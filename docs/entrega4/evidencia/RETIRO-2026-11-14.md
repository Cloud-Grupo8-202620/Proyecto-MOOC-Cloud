# Retiro del despliegue — 2026-11-14

Se ejecutó `terraform destroy` sobre `scripts/IaC/cloudrun` en
`proyecto-2-cloud-509714`.

## Eliminado

- Servicios Cloud Run `mooc4-frontend`, `mooc4-backend`, `mooc4-worker`.
- Job `mooc4-provision-admin`.
- Cloud SQL `mooc4-postgres`, base de datos y usuario.
- Memorystore `mooc4-redis`.
- Topic, suscripciones, DLQ y políticas de Pub/Sub.
- Buckets `mooc4-*-originals`, `mooc4-*-hls`, `mooc4-*-public`.
- VM de soporte `mooc4-support`, IP interna, firewalls, NAT y router.
- Artifact Registry `mooc4-images`.
- Secretos, cuentas de servicio, claves HMAC y reglas IAM.
- Los servicios Cloud Run conservan `deletion_protection = false` en Terraform
  para que el retiro sea reproducible.

## Pendiente

Cloud Run reserva una IP serverless (`10.10.1.32`) en la subred
`mooc4-app-subnet`. Google documenta que la libera 1–2 horas después de retirar
los servicios, y no permite borrarla manualmente mientras exista la reserva.
Por eso quedan temporalmente:

- `mooc4-vpc`
- `mooc4-app-subnet`
- `serverless-ipv4-cloudrun-1794693356873039361`

El state de Terraform conserva la VPC y la subred. Cuando la IP se libere, basta
repetir:

```bash
cd scripts/IaC/cloudrun
terraform destroy -auto-approve
```

La API de Cloud Run quedó deshabilitada, como estaba antes del despliegue.
